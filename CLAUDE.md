## Project Overview

**Letters Home** is an interactive documentary website following FTG3 Mike Ducy's 1968 WestPac deployment aboard USS Jouett (DLG-29) during the Vietnam War. The site presents 187 days of primary source materials — logbook entries, letters, audio recordings, photographs, Super 8 film, and official documents — organized chronologically and geographically.

Live site: https://vietnam.ducy.org
Media CDN: https://vietnam-ducy-media.s3.amazonaws.com

## Architecture

### Stack

- **Astro 7.x** — static site generator with islands architecture
- **Preact 11** — interactive components (map, lightbox, audio player, archive)
- **Leaflet** — deployment map with custom CRT-green military aesthetic
- **Vanilla CSS** — no frameworks, CSS custom properties for theming
- **GitHub Pages** — static hosting via GitHub Actions
- **AWS S3** — media storage (images, audio, video)

### Media URL Pattern

Media paths use a `PUBLIC_MEDIA_URL` env var set at build time via Vite:

- **Local dev**: empty string, paths resolve to `/media/photos/...` (local files)
- **Production**: `https://vietnam-ducy-media.s3.amazonaws.com`, paths become `https://...s3.amazonaws.com/photos/...`

Every page that references media has an `m()` helper that strips the `/media` prefix when `MEDIA_URL` is set:

```typescript
const MEDIA_URL = import.meta.env.PUBLIC_MEDIA_URL || '';
function m(path: string | undefined): string | undefined {
  if (!path) return path;
  if (!MEDIA_URL) return path;
  return MEDIA_URL + path.replace(/^\/media/, '');
}
```

S3 bucket stores files without the `/media/` prefix (e.g., `s3://vietnam-ducy-media/photos/...`).

## Data Pipeline

### Source of Truth

The master timeline lives outside this repo:

```
/Users/michael/Movies/Home Movies/Vietnam Project/Documentation/Mike Ducy Log Book/deployment-timeline.md
```

This is a markdown file with tables (`| Date | Day# | Entry |`) covering all 187 days. It is the canonical record — all other data derives from it.

### Pipeline Steps

#### 1. Parse timeline → JSON

```bash
python3 scripts/parse_timeline.py
```

Reads `deployment-timeline.md` → writes `src/data/timeline.json`. Extracts dates, day numbers, entries, locations (pattern-matched), quotes, sources, significance flags.

#### 2. Copy and process media

```bash
python3 scripts/copy_media.py [--category photos|letters|documents|logbook|slides|video|audio|all]
```

Scans the Vietnam Project directories, converts HEIC→JPEG (via `sips`), generates thumbnails, applies watermarks, and writes to `public/media/`. Also generates `src/data/media-manifest.json`. Dates extracted from filenames (`YYYYMMDD - description.ext`). Audio tape filenames use natural-language dates (e.g., `Tape 1 - Mike Ducy April 14th to 16th 1968.WAV`) — these are matched by a hardcoded pattern list in `extract_date()`.

**Video watermarking**: Videos are watermarked via ffmpeg overlay — Pillow generates a transparent PNG with the watermark text, ffmpeg composites it onto the video. Video thumbnails are also extracted via ffmpeg (frame 30).

**SSN redaction**: The script warns about DD-214 and ACDUTRA files that contain SSNs. These must be manually redacted before publishing.

#### 3. Build transcripts

```bash
python3 scripts/build_transcripts.py
```

Aggregates transcripts from multiple sources into `src/data/transcripts.json`:
- Letter transcripts (from `letter-transcripts.json`)
- Familygrams (from `DLG-29 Family Grams/transcripts/`)
- Audio transcripts (from Whisper ASR output in `Audio Cassettes/denoised recordings/transcripts/`)
- Document transcripts (from `Documentation/Misc/transcripts/`, ship publications, newspaper clippings, etc.)
- Cruise book transcripts (from `Cruise Book - 1968/transcripts/`)
- Vigilance magazine transcript

#### 4. Update logbook entries from transcription

```bash
python3 scripts/parse_logbook_transcription.py
python3 scripts/update_timeline_from_transcription.py
```

First script parses `logbook-transcription.txt` → `logbook-transcripts.json` (keyed by ISO date, mapped via HEIC filenames).
Second script updates `[Logbook]`-tagged entries in `deployment-timeline.md` with the corrected transcription text.

#### 5. Build slideshows

```bash
python3 scripts/build_slideshows.py
```

Reads TIMING-GUIDE files and Whisper transcript JSONs to create `slideshows.json` — maps each slide image to its audio time range and transcript segments for synchronized playback.

#### 6. Upload media to S3

```bash
./scripts/upload_media.sh [--dry-run]
```

Syncs `public/media/` to `s3://vietnam-ducy-media` using AWS CLI. Excludes WAV files (MP3 versions used instead).

#### 7. Rebuild manifest (without re-copying)

```bash
python3 scripts/rebuild_manifest.py
```

Scans existing `public/media/` directory and regenerates `media-manifest.json` without copying or converting files. Useful after manual edits to media.

### Typical Update Workflow

When new transcriptions or media are added:

```bash
# 1. Update the timeline if entries changed
python3 scripts/parse_timeline.py

# 2. Copy any new media files
python3 scripts/copy_media.py --category letters

# 3. Rebuild transcripts
python3 scripts/build_transcripts.py

# 4. Build and verify locally
npm run dev

# 5. Upload new media to S3
./scripts/upload_media.sh --dry-run   # preview
./scripts/upload_media.sh             # sync

# 6. Push to deploy
git add -A && git commit && git push
```

## Transcription Methods

### Logbook Pages (Image → Text)

**Method**: Claude vision (multimodal LLM)

The 187 logbook pages were photographed as HEIC files. Claude was used to transcribe the handwritten entries by processing rotated JPEGs in parallel forks. The process:

1. HEIC photos in `/Users/michael/Movies/Home Movies/Vietnam Project/Documentation/Mike Ducy Log Book/` named `YYYYMMDD - IMG_XXXX Logbook.HEIC`
2. Claude vision reads each image and produces text transcription
3. Output collected in `logbook-transcription.txt` with `=== IMG_XXXX ===` headers
4. `parse_logbook_transcription.py` maps IMG IDs → dates via HEIC filenames and outputs `logbook-transcripts.json`
5. `update_timeline_from_transcription.py` patches `deployment-timeline.md` with corrected text

**Known issues**: OCR can produce ALL CAPS or garbled location names. The site uses case-insensitive location matching on the map page to handle this.

### Letters and Documents (Image → Text)

**Method**: Claude vision (multimodal LLM)

Handwritten and typed letters/documents were transcribed using Claude vision. Transcript files are stored as `.txt` alongside the source images in the Vietnam Project directories, then aggregated by `build_transcripts.py`.

### Audio Cassettes (Speech → Text)

**Method**: MLX Whisper on Apple Silicon

Script: `/Users/michael/Music/Cassette recordings/transcribe.sh`

```bash
./transcribe.sh                          # all files recursively
./transcribe.sh "Viet Nam"               # specific subdirectory
./transcribe.sh recording.WAV            # single file
```

Configuration:
- **Model**: `mlx-community/whisper-large-v3-mlx` (runs locally on Apple Silicon GPU via MLX)
- **Anti-hallucination**: `--condition-on-previous-text False` prevents repetition loops on noisy cassette audio
- **Silence threshold**: `--hallucination-silence-threshold 1.0` skips silent sections
- **Output**: generates `.txt`, `.json`, `.srt`, `.vtt` in a `transcripts/` subdirectory next to each audio file
- **Whisper JSON** includes `start`/`end`/`text` segments used for synchronized transcript scrolling in the audio player and slideshow components

The denoised recordings (processed separately from raw cassette audio) are the source for web playback. MP3 versions are uploaded to S3; WAV originals are not.

### Map Page Notes

- `locations.json` stores real geographic coordinates (positive for Asian locations)
- `map.astro` shifts positive longitudes to negative at runtime for Pacific-centered view
- Leaflet CSS loaded via static `<link>` in Layout.astro head (not dynamically — fixes race condition)
- `box-sizing: content-box` scoped to `.leaflet-pane *` and `.leaflet-control *` only (not all `.leaflet-container *` — that breaks our custom map UI)
- Jan 16 and Jul 18 are special-cased to San Diego in location matching
- Location matching is case-insensitive (handles ALL CAPS from OCR transcription)
- Route uses `pinCoords()` helper reading from shifted pin positions

### Map Tutorial

6-step guided walkthrough stored in `DeploymentMap.tsx`. Persists completion in `localStorage` (`map-tutorial-done`). Replayable via `?` button in the map legend. Uses a bouncing `▶` pointer positioned via DOM queries on `data-tutorial-id` attributes.

### Map Mobile Layout

- Pin tap flies/centers the map on the location
- **Portrait**: Panel slides up from bottom (50% height), drag handle at top to expand to 85%
- **Landscape**: Panel on the right side like desktop (50% width), expandable to 75%
- Uses `panelExpanded` state and `.panel-expanded` CSS class

### Archive Page

- Uses `client:only="preact"` (NOT `client:load`) to avoid SSR hydration mismatch with URL hash anchors
- Tabs support `#anchor` URLs (e.g., `/archive#audio`) — hash is read on mount and updated on tab switch
- Video grid items use `<img>` thumbnails with play badge overlay, NOT `<video>` elements

### Content Display

- Letters and audio transcripts open by default (`<details open>`)
- Familygrams, documents, vigilance, and cruise book transcripts collapsed by default (no `open` attribute)
- Do NOT touch logbook format
- Audio/video elements use `controlsList="nodownload"` and `onContextMenu` prevention (JSX camelCase: `controlsList`, not `controlslist`)

### Transcript Matching

Audio transcripts are matched to media items bidirectionally — check both `caption.includes(match_key)` AND `match_key.includes(caption)`. This is needed because some filenames have date prefixes in one system but not the other. This pattern must be consistent in both `DeploymentMap.tsx` (map modal) and `day/[...date].astro` (timeline).

## Sensitive Data

- **DD-214** contains Mike's SSN — must be redacted before publishing
- **ACDUTRA orders** also contain SSN — must be redacted
- `copy_media.py` warns about these files but does not auto-redact
- Never commit credentials, SSNs, or unredacted sensitive documents

## Common Tasks

### Add a new transcript

1. Place `.txt` file in the appropriate `transcripts/` directory under the Vietnam Project
2. Name it `YYYYMMDD - Description.txt`
3. Run `python3 scripts/build_transcripts.py`
4. Verify with `npm run dev`

### Add new photos/media

1. Place files in the appropriate Vietnam Project directory
2. Name them `YYYYMMDD - Description.ext`
3. Run `python3 scripts/copy_media.py --category photos`
4. Run `./scripts/upload_media.sh`
5. Verify locally and push

### Update logbook entries

1. Edit `logbook-transcription.txt` with corrected text
2. Run `python3 scripts/parse_logbook_transcription.py`
3. Run `python3 scripts/update_timeline_from_transcription.py`
4. Run `python3 scripts/parse_timeline.py`
5. Verify with `npm run dev`

### Re-transcribe audio

```bash
# Delete existing transcript to force re-transcription
rm "/path/to/transcripts/filename.txt"
/Users/michael/Music/Cassette recordings/transcribe.sh "/path/to/audio.WAV"
python3 scripts/build_transcripts.py
```
